# Guess-number

A guess-the-number game with a Tkinter GUI. The player picks a difficulty (ranges 1-10, 1-50, 1-100, 1-500, or "Crazy" 1-200 where the target number is re-rolled on every guess) and gets higher/lower hints until they find the number.

## How to run

Requires Python 3 with Tkinter (included in most standard Python installs).

```
python GuessNumber.py
```
